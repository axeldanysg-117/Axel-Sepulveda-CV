# Prompts utilizados

## Prompt principal

> Convierte el archivo `cv.html` en una página web curricular completa, organizada en `index.html`, `css/styles.css` y `js/interactions.js`. Conserva la información personal y académica, mejora la estructura semántica, la responsividad y la accesibilidad, y elimina errores visibles del contenido original.

## Prompt de diseño

> Crea una identidad visual profesional con una paleta azul institucional, disposición adaptable para escritorio y móvil, tarjetas para proyectos, navegación por secciones y un botón flotante de contacto.

## Prompt de interacciones

> Implementa un botón accesible para mostrar u ocultar información adicional y una galería con controles de anterior y siguiente, indicador de posición y soporte para lectores de pantalla.
